Softub Electronics Conversion – Visual Overview

Original control board → modern smart home components

STEP 1
Remove original
Fully remove control board, Zettler relay, Isonic valve, Aquatemp transformer. Label all wires.
STEP 2
Terminal block montieren
Central L/N/PE distribution on a sturdy mount. Starting point for all new components.
STEP 3
Wire the smart components
TH16A (temperature) → Shelly (control signal) → Kemo (power controller) → pump + ozonator in parallel.
STEP 4
Test & configure
Set Shelly min/max in app (35–100%), TH16A target temperature, function test without water.
